📌 Project Overview

This project involves creating a profile card using HTML and CSS. The CSS Box Model is used to manage the spacing, borders, padding, and dimensions of the profile card.

🎯 Objectives

* Create a profile card using HTML.
* Understand and implement the CSS Box Model.
* Use margin, padding, border, and content properties.
* Style the card with colors, fonts, and alignment.
* Create a clean and attractive design.

🛠️ Technologies Used

* HTML5 – For creating the structure of the profile card.
* CSS3 – For styling the card and implementing the Box Model.

✨ Features

* Profile image and personal details.
* Attractive card layout.
* Proper padding and margins.
* Border and rounded corners.
* Styled text and background colors.
* Clean and user-friendly design.

📦 CSS Box Model

The CSS Box Model consists of four main parts:

1. Content: Contains the profile image, name, and details.
2. Padding: Adds space between the content and border.
3. Border: Surrounds the content and padding.
4. Margin: Adds space outside the card.
